* Writer: 写入器，提供了**Render Products**、**Parameters 、**Output** 和 **Config** 选项的访问
  其中Render Products、Parameters、Output、Config功能选项

## Writer frame

The **Writer** frame provides access to **Render Products**, **Parameters**, **Output**, and **Config** options.

在Writer frame栏中，可以使用**Add New Render Product** button去创建一系列产品渲染记录器组，在一般情况下我们将使用活动的摄像机作为记录器，然后在Render Products中可以进行选择记录器在场景中的路径

<img src="D:\Soft\Typora\markdown_data\数据生成.assets\isim_4.5_replicator_tut_gui_sd_recorder_rp-1750231418747-7.jpg" alt="Synthetic Data Recorder Render Products" style="zoom:200%;" />

如果对舞台浏览器的摄像机进行选择将会将摄像机添加到记录器组中，在记录器组中可以存在多个同地址的摄像机，每个摄像机的分辨路能够在组内进行编辑

## Control

**控制**帧包含录制功能（如开始/停止和暂停/恢复）和参数（如要录制的帧数或要为每个录制的帧渲染的子帧数）。

- The **Start** button creates a writer, given the selected parameters, and starts the recording.按钮会创建一个写入器，给定选定的参数，然后开始录制。
- The **Stop** button stops the recording and clears the writer.按钮可停止录制并清除写入器。
- The **Pause** button pauses the recording without clearing the writer. 按钮可暂停录制，而不清除 writer。
- The **Resume** button resumes the recording.按钮可恢复录制。
- The **Number of Frames** input field sets the number of frames to record, after which the recorder is stopped and the writer cleared. If the value is set to 0, the recording runs indefinitely or until the **Stop** button is pressed.**帧数**） 输入字段设置要录制的帧数，之后将停止录制器并清除写入器。如果该值设置为 0，则录制将无限期运行，或直到按下 **Stop （停止**） 按钮。
- The **RTSubframes** field sets the number of additional subframes to render for each per frame. This can be used if randomized materials are not loaded in time or if temporal rendering artifacts (such as ghosting) are present due to objects being teleported.字段设置每帧要为每个子帧渲染的其他子帧的数量。如果随机化材质未及时加载，或者由于对象被传送而存在时间渲染瑕疵（例如重影），则可以使用此选项。
- The **Control Timeline** checkbox starts/stops/pauses/resumes the timeline together with the recorder. 记录摄像机开始/停止/暂停/恢复时间线。
- The **Verbose** checkbox enables verbose logging for the recorder (events such as start, stop, pause, resume, and the number of frames recorded).为摄像机器启用详细日志记录（例如开始、停止、暂停、恢复和录制的帧数等事件）

![Synthetic Data Recorder Output and Config](D:\Soft\Typora\markdown_data\数据生成.assets\isim_4.5_replicator_tut_gui_sd_recorder_control.jpg)

> 注意：要提高渲染质量，或避免由低光照条件或快速移动的对象引起的任何渲染伪影，请增加 **RTSubframes** 参数。这将为每帧渲染多个子帧，从而提高记录数据的质量，但代价是每帧的渲染时间更长。有关更多详细信息，请参阅[子帧](https://docs.omniverse.nvidia.com/extensions/latest/ext_replicator/subframes_examples.html#subframes-examples)文档。





## Custom Writer Example自定义记录器

要支持自定义数据格式，可以从 GUI 注册和加载自定义写入器。在此示例中，使用 [Script Editor](https://docs.isaacsim.omniverse.nvidia.com/4.5.0/development_tools/omniverse_script_editor.html#script-editor) 注册了一个名为 的自定义编写器，以便与录制器一起使用。`MyCustomWriter`

```
import numpy as np
from omni.replicator.core import AnnotatorRegistry, BackendDispatch, Writer, WriterRegistry

class MyCustomWriter(Writer):
    def __init__(
        self,
        output_dir,
        rgb = True,
        normals = False,
    ):
        self.version = "0.0.1"
        self.backend = BackendDispatch({"paths": {"out_dir": output_dir}})
        if rgb:
            self.annotators.append(AnnotatorRegistry.get_annotator("rgb"))
        if normals:
            self.annotators.append(AnnotatorRegistry.get_annotator("normals"))
        self._frame_id = 0

    def write(self, data: dict):
        for annotator in data.keys():
            # If there are multiple render products the data will be stored in subfolders
            annotator_split = annotator.split("-")
            render_product_path = ""
            multi_render_prod = 0
            if len(annotator_split) > 1:
                multi_render_prod = 1
                render_product_name = annotator_split[-1]
                render_product_path = f"{render_product_name}/"

            # rgb
            if annotator.startswith("rgb"):
                if multi_render_prod:
                    render_product_path += "rgb/"
                filename = f"{render_product_path}rgb_{self._frame_id}.png"
                print(f"[{self._frame_id}] Writing {self.backend.output_dir}/{filename} ..")
                self.backend.write_image(filename, data[annotator])

            # semantic_segmentation
            if annotator.startswith("normals"):
                if multi_render_prod:
                    render_product_path += "normals/"
                filename = f"{render_product_path}normals_{self._frame_id}.png"
                print(f"[{self._frame_id}] Writing {self.backend.output_dir}/{filename} ..")
                colored_data = ((data[annotator] * 0.5 + 0.5) * 255).astype(np.uint8)
                self.backend.write_image(filename, colored_data)

        self._frame_id += 1

    def on_final_frame(self):
        self._frame_id = 0

WriterRegistry.register(MyCustomWriter)
```

my_params.json

```
{
    "rgb": true,
    "normals": true
}
```

## Replicator 随机摄像机

要利用 Replicator 随机化技术，可以在启动录制器之前使用[脚本编辑器](https://docs.isaacsim.omniverse.nvidia.com/4.5.0/development_tools/omniverse_script_editor.html#script-editor)加载随机化摄像机，以便在录制期间运行场景随机化。在此示例中，使用 Replicator API 创建随机摄像机。这可以作为渲染产品附加到录制器，并且对于每一帧，摄像机都使用给定的参数随机化。

## 录制循环概述

**Synthetic Data Recorder** 是 Isaac Sim 的 GUI 扩展，它使用或自定义 Replicator 写入器来捕获数据。它的实现位于并利用该功能来管理录制过程。此功能通过等待渲染器中的任何“飞行中的帧”来确保录制的帧与舞台保持同步。为了与 UI 集成，录制器使用以下函数的异步版本：。`BasicWriter``/isaacsim.replicator.synthetic_recorder/isaacsim/replicator/synthetic_recorder/synthetic_recorder.py``orchestrator.step(rt_subframes, pause_timeline, delta_time)``step_async`

> ```
> while self._current_frame < num_frames:
>     timeline = omni.timeline.get_timeline_interface()
> 
>     if self.control_timeline and not timeline.is_playing():
>         timeline.play()
>         timeline.commit()
> 
>     await rep.orchestrator.step_async(rt_subframes=self.rt_subframes, delta_time=None, pause_timeline=False)
> 
>     self._current_frame += 1
> ```

录制循环为不同的用例提供了灵活性。它可以提前动态场景（如模拟或动画）的时间轴，也可以在不提前静态捕获的时间轴的情况下运行。此方法支持录制随机化视图、调整光照条件或重新定位对象等场景。
