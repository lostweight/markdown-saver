# Bobac 机器人办公室物品搬运课程 - 完整大纲

## 课程概述

本课程基于 Bobac 机器人和 Isaac Sim 仿真平台，系统讲解如何实现办公室场景中的智能物品搬运任务。课程涵盖从任务分析、硬件建模、仿真搭建、关节控制、自主导航到抓取放置的完整技术栈。

**课程特色**：
- ✅ 理论与实践结合，每章都有实战案例
- ✅ 基于真实工作空间代码（/workspace/bobac_ws/src）
- ✅ 从仿真到真机的完整开发流程
- ✅ 涵盖 ROS2、Isaac Sim、MoveIt2、Nav2 等主流技术

## 第二章：Bobac 机器人结构与硬件参数

### 学习目标
- 掌握 Bobac 机器人的整体结构
- 理解差速驱动底盘的运动学原理
- 掌握 6 自由度机械臂的 DH 参数
- 了解传感器配置和数据格式

### 核心内容

#### 2.1 机器人整体介绍
- 组成部分：底盘、机械臂、传感器、计算平台
- 规格参数：尺寸、重量、续航、负载

#### 2.2 移动底盘系统
- **结构**：四轮差速驱动（前轮主动，后轮从动）
- **运动学参数**：
  - 轮距：0.38m
  - 轮半径：0.075m
  - 最大速度：1.0 m/s
- **差速驱动原理**：
  ```
  v_left = v - (ω × wheel_base) / 2
  v_right = v + (ω × wheel_base) / 2
  ```
- **坐标系**：ROS 标准坐标系（X 前，Y 左，Z 上）

#### 2.3 机械臂系统
- **结构**：ECO65-B 6 自由度串联机械臂
- **关节配置**：
  - joint1-6：旋转关节
  - 总自由度：6 DOF
- **关节运动范围**：
  - joint1: ±180°
  - joint2: -90° ~ 90°
  - joint3: -135° ~ 135°
  - joint4: ±180°
  - joint5: -90° ~ 90°
  - joint6: ±180°
- **DH 参数表**：描述各关节的运动学关系
- **性能参数**：
  - 工作半径：0.65m
  - 最大负载：2kg
  - 重复定位精度：±0.5mm

#### 2.4 传感器系统
- **激光雷达**：N10P，360° 扫描，测距 0.1-25m
- **深度相机**：IMX219 双目，800 万像素，基线 60mm
- **IMU**：ICM20948，9 轴传感器
- **轮式编码器**：2048 线/圈，±0.1% 精度

#### 2.5 坐标系统
- TF 树结构：map → odom → base_link → 各传感器/机械臂
- 主要坐标系：map、odom、base_link、laser_link、arm_camera_link

### 关键要点
- 差速驱动通过左右轮速度差实现转向
- DH 参数是机械臂运动学建模的标准方法
- 传感器数据需要通过 TF 变换到统一坐标系
- 硬件参数必须准确，否则影响仿真真实性

## 第三章：Isaac Sim 资产准备与机器人组装

### 学习目标
- 掌握 Isaac Sim 资产管理方法
- 理解 URDF 机器人描述格式
- 掌握关节链、刚体、关节树等核心概念
- 理解碰撞网格的作用和配置方法

### 核心内容

#### 3.1 Isaac Sim 资产管理
- **资产类型**：机器人模型、环境模型、传感器、材质
- **资产格式**：USD、URDF、OBJ、FBX、STL
- **导入流程**：准备 → 导入 → 配置 → 保存 → 使用

#### 3.2 URDF 模型构建
- **Link（连杆）**：
  - 视觉模型：用于渲染显示
  - 碰撞模型：用于物理仿真
  - 惯性参数：质量、惯性矩阵
- **Joint（关节）**：
  - 类型：revolute、prismatic、fixed
  - 参数：运动范围、速度限制、力矩限制
  - 动力学：阻尼、摩擦

#### 3.3 关节链（Articulation）
- **定义**：多刚体通过关节连接形成的系统
- **作用**：
  - 运动学建模
  - 动力学模拟
  - 统一控制接口
  - 碰撞检测
- **组成**：Articulation Root + Rigid Body + Joint

#### 3.4 刚体（Rigid Body）
- **定义**：不发生形变的物体
- **属性**：
  - 质量：kg
  - 惯性矩阵：3×3 矩阵
  - 质心位置：相对坐标
  - 材质属性：摩擦系数、恢复系数

#### 3.5 关节树（Kinematic Tree）
- **定义**：描述机器人运动学结构的树状数据结构
- **作用**：
  - 正向运动学：关节角度 → 末端位姿
  - 逆向运动学：末端位姿 → 关节角度
  - 雅可比矩阵：关节速度 → 末端速度
  - 碰撞检测优化
- **与 TF 树的关系**：关节树对应 TF 树

#### 3.6 碰撞网格（Collision Mesh）
- **定义**：用于碰撞检测的简化几何模型
- **类型**：
  - 基本几何体：盒子、球体、圆柱（速度快）
  - 凸包：包围物体的最小凸多面体（平衡）
  - 三角网格：精确模型（精度高）
- **设计原则**：
  - 简化原则：尽可能少的几何体
  - 精度原则：关键部位高精度
  - 性能原则：减少计算量

#### 3.7 组件关系
```
URDF → 关节树 → 刚体 + 关节
刚体 = 视觉网格 + 碰撞网格 + 物理属性
关节链 = 统一管理 + 控制接口
```

### 关键要点
- URDF 是 ROS 机器人的标准描述格式
- 关节链是 Isaac Sim 中多刚体系统的核心
- 碰撞网格要简化，视觉网格要精确
- 物理属性（质量、惯性）必须准确配置

## 第四章：Isaac Sim 关节控制与 ActionGraph

### 学习目标
- 理解关节控制器的工作原理
- 掌握 ROS2 与 Isaac Sim 的通信机制
- 学会使用 ActionGraph 进行可视化编程
- 理解 ActionGraph 在机器人控制中的作用

### 核心内容

#### 4.1 关节控制基础
- **控制模式**：
  - 位置控制：控制关节到达指定角度
  - 速度控制：控制关节以指定速度运动
  - 力矩控制：控制关节输出指定力矩
- **控制层次**：
  - 高层：ROS2 Action/Topic
  - 中层：关节控制器
  - 底层：物理引擎
  - 执行层：关节驱动

#### 4.2 关节控制器（Joint Controller）
- **PID 控制原理**：
  ```
  输出 = Kp × 误差 + Ki × 积分 + Kd × 微分
  ```
- **关键参数**：
  - stiffness：刚度（位置控制增益）
  - damping：阻尼（速度控制增益）
  - max_effort：最大力矩限制
  - max_velocity：最大速度限制

#### 4.3 ROS2 与 Isaac Sim 通信
- **ROS2 Bridge**：数据转换 + 时间同步 + TF 发布
- **关节状态发布**：`/joint_states` (sensor_msgs/JointState)
- **关节控制接收**：`/hand_command` (sensor_msgs/JointState)
- **底盘速度控制**：`/cmd_vel` (geometry_msgs/Twist)

#### 4.4 ActionGraph 可视化编程
- **定义**：通过拖拽节点构建逻辑流程
- **节点类型**：
  - 事件节点：On Tick、On Impulse Event
  - 输入节点：ROS2 Subscribe、Get Prim Attribute
  - 处理节点：Math、Logic、Array
  - 输出节点：ROS2 Publish、Set Prim Attribute
- **优势**：
  - 可视化编程，直观易懂
  - 实时执行，即时反馈
  - 模块化设计，易于复用

#### 4.5 ActionGraph 示例
- **底盘控制**：订阅 /cmd_vel → 差速控制器 → 设置轮速
- **机械臂控制**：订阅 /hand_command → 关节控制器 → 设置关节位置
- **状态反馈**：获取关节状态 → 发布 /joint_states

#### 4.6 ActionGraph vs Python
- ActionGraph：适合简单逻辑、快速原型
- Python：适合复杂算法、高性能计算
- 推荐：两者结合，发挥各自优势

### 关键要点
- 关节控制器基于 PID 控制
- ROS2 Bridge 实现仿真与 ROS2 的无缝对接
- ActionGraph 适合快速搭建控制逻辑
- 复杂算法建议使用 Python 脚本

## 第五章：导航功能实现

### 学习目标
- 理解自主导航系统的整体架构
- 掌握 ROS2 Nav2 导航栈的使用
- 理解 AMCL 定位算法原理
- 掌握全局和局部路径规划算法
- 学会配置和调试导航系统

### 核心内容

#### 5.1 导航系统概述
- **核心问题**：
  - 我在哪里？（定位）
  - 我要去哪里？（目标设定）
  - 怎么去？（路径规划）
  - 如何避障？（避障控制）
- **系统组成**：传感器 → 感知 → 定位/建图 → 规划 → 控制 → 执行

#### 5.2 ROS2 Nav2 导航栈
- **核心组件**：
  - BT Navigator：行为树导航器，任务协调
  - Planner Server：全局路径规划
  - Controller Server：局部路径规划
  - Behavior Server：恢复行为
  - AMCL：定位模块
  - Map Server：地图管理
  - Costmap：代价地图
  - Velocity Smoother：速度平滑

#### 5.3 AMCL 定位算法
- **原理**：基于粒子滤波的自适应定位
- **算法步骤**：
  1. 初始化粒子
  2. 运动预测（根据里程计）
  3. 观测更新（根据激光雷达）
  4. 权重计算
  5. 重采样
  6. 位姿估计
- **关键参数**：
  - min_particles: 300
  - max_particles: 1500
  - update_min_d: 0.15m
  - update_min_a: 0.1rad

#### 5.4 全局路径规划（SmacPlanner2D）
- **算法**：基于 A* 的改进版本
- **评估函数**：f(n) = g(n) + h(n)
- **代价地图**：
  - 静态层：地图文件
  - 障碍物层：传感器数据
  - 膨胀层：安全距离
- **代价值**：0（自由）~ 254（致命）~ 255（未知）

#### 5.5 局部路径规划（MPPI Controller）
- **原理**：模型预测路径积分控制
- **工作流程**：
  1. 采样 2000 条候选轨迹
  2. 评估每条轨迹的代价
  3. 选择代价最小的轨迹
  4. 执行第一步控制指令
- **评价器**：
  - ConstraintCritic：约束违反
  - ObstaclesCritic：障碍物碰撞
  - CostCritic：代价地图
  - PathFollowCritic：路径跟随
  - GoalCritic：目标距离

#### 5.6 行为树导航器
- **作用**：
  - 任务协调
  - 错误恢复
  - 灵活配置
- **结构**：
  - NavigateRecovery：导航恢复
  - NavigateWithReplanning：带重规划的导航
  - RecoveryFallback：恢复回退

#### 5.7 在 Isaac Sim 中实现导航
- 创建仿真场景
- 加载机器人
- 启动 Nav2
- 建图（SLAM）
- 发送导航目标

### 关键要点
- Nav2 是 ROS2 的官方导航框架
- AMCL 使用粒子滤波进行定位
- 全局规划使用 A* 算法
- 局部规划使用 MPPI 控制器
- 行为树协调各模块，处理错误恢复

## 第六章：抓取放置功能实现

### 学习目标
- 理解机器人抓取系统的整体架构
- 掌握 YOLOE 视觉检测技术
- 掌握 MoveIt2 运动规划框架
- 学会使用状态机编排复杂任务
- 理解夹爪控制的实现方法

### 核心内容

#### 6.1 抓取系统概述
- **核心问题**：
  - 看到什么？（视觉识别）
  - 在哪里？（位置估计）
  - 怎么抓？（抓取规划）
  - 抓稳了吗？（力控制）
- **系统组成**：视觉感知 → 抓取规划 → 运动规划 → 控制执行

#### 6.2 视觉检测模块（YOLOE）
- **功能包**：yoloe_grasp
- **核心功能**：
  - 物体检测：YOLOE 模型推理
  - 实例分割：提取物体轮廓
  - 深度估计：反投影到 3D
  - 姿态估计：计算法向量和长轴
- **深度反投影**：
  ```
  x = (u - cx) * z / fx
  y = (v - cy) * z / fy
  z = z
  ```
- **抓取点生成**：
  - 法向量：fixed_base / local_plane / camera_side
  - 长轴：PCA 主成分分析

#### 6.3 MoveIt2 运动规划
- **功能包**：
  - eco65b_moveit_description：URDF/SRDF
  - eco65b_moveit_config：配置文件
  - eco65b_moveit_grasp：运动规划节点
- **核心功能**：
  - 逆运动学求解
  - 轨迹规划（OMPL）
  - 碰撞检测
  - 笛卡尔路径规划
- **规划流程**：
  1. 接收目标位姿
  2. 逆运动学求解
  3. 碰撞检测
  4. 轨迹规划
  5. 轨迹优化
  6. 轨迹执行

#### 6.4 状态机编排
- **功能包**：grasp_control
- **抓取流程**：
  1. 移动到观察位置
  2. 检测物体
  3. 移动到预抓取位置
  4. 打开夹爪
  5. 移动到抓取位置
  6. 关闭夹爪
  7. 提升物体
- **放置流程**：
  1. 移动到观察位置
  2. 检测容器
  3. 计算旋转姿态
  4. 移动到预放置位置
  5. 移动到放置位置
  6. 打开夹爪
  7. 等待物体稳定
  8. 返回

#### 6.5 夹爪控制
- **Action 接口**：/gripper_control
- **控制命令**：
  - open：打开夹爪
  - close：关闭夹爪
  - position：指定位置（0-100%）
- **实现**：发布 JointState 到 /hand_command

#### 6.6 完整抓取流程
- 启动 MoveIt2
- 启动运动规划节点
- 启动视觉检测节点
- 启动夹爪控制节点
- 启动抓取状态机
- 执行抓取任务

### 关键要点
- YOLOE 提供物体检测和分割
- 深度反投影将 2D 坐标转换为 3D
- MoveIt2 提供完整的运动规划解决方案
- 状态机编排复杂的多步骤任务
- 预抓取位置保证安全接近
